NAS & Nextcloud Sync for Odoo

Your Odoo attachments, automatically copied to Synology, QNAP, TrueNAS or Nextcloud — in clean, human-readable folders.

One module · No extra paid dependencies · Set up in 5 minutes

📁 Folders that make sense

Files land in Odoo/Invoices/INV-2026-0042 (42)/scan.pdf. Anyone in the office can find them from Windows Explorer, Finder or the NAS app.

⚙️ You choose what to sync

Pick document types (invoices, sale orders, employees, projects…), filter records with a domain, and choose whether to include old files.

🔁 Fully automatic

A scheduled job uploads new attachments every 15 minutes. Failed uploads are retried automatically and listed in a clear sync log.

🔒 Your data stays yours

Files go straight from your Odoo server to your own NAS over HTTPS. No third-party cloud, no subscription.

See it in action

Works with

  • Synology DSM (WebDAV Server package)
  • QNAP QTS (built-in WebDAV)
  • TrueNAS (WebDAV service)
  • Nextcloud / ownCloud (incl. app passwords)
  • Any RFC 4918 WebDAV server

Setup in 3 steps

  1. Open NAS Sync → Servers, enter the WebDAV URL, username and password.
  2. Click Test connection.
  3. Add the document types you want under What to sync. Done.

Features

  • Multiple NAS servers; multi-company: each server can sync only one company's documents
  • One folder per document type, optional subfolder per record
  • Renamed record? Its folder is renamed on the NAS too (no re-upload)
  • Changed files re-uploaded over the old copy; unchanged ones are skipped
  • Record filters (domain) and “only files created after” date
  • Optional: delete the NAS copy when the file is deleted in Odoo
  • Duplicate file names handled automatically
  • Sync log with status, errors and one-click retry
  • Self-signed certificates supported (for local NAS)

Requirements

Odoo 19 Community or Enterprise, on Odoo.sh or on-premise. Your Odoo server must be able to reach the NAS (public HTTPS address, VPN or same network).
